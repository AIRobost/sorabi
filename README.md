# Sorabi 空灯

壁のテレビやサブモニターに出しっぱなしにする、日本国内向けの天気表示です。
空そのものを背景に描き、夜は気温の数字がネオンのように灯ります。

**https://airobost.github.io/sorabi/**

インストールは不要です。上のURLをブラウザで開くだけで使えます。

![夜の表示(デザイン「墨」)](screenshots/sumi-night.jpg)

![昼の表示(デザイン「墨」)](screenshots/sumi-day.jpg)

同じ地点の夜と昼です。日が沈むと、気温・天気・地名がネオンとして灯ります。

## 特徴

- 天気と時刻に合わせて、空・雲・雨・雪・霧・雷を背景に描きます。太陽は実際の位置を動きます
- 雨と雪の強さは降水量に連動し、風があれば斜めに降ります
- 夕方から、気温・天気・地名がネオンとして灯ります。色は気温で変わり、固定色も選べます
- 気象庁の警報・注意報を控えめに表示します
- デザインは3種類(墨・計・環)。縦置き・横置き、4Kにも対応します
- 全国1,894市区町村から、都道府県・ひらがな/漢字の検索・現在地で地点を選べます
- 10分ごとに自動更新します

## 使い方

1. [https://airobost.github.io/sorabi/](https://airobost.github.io/sorabi/) を開き、表示する地点を選びます
2. `F11` キーで全画面にします
3. そのまま出しっぱなしにします。選んだ地点と設定はブラウザに保存されます

画面の操作は次のとおりです。

- **詳細を見る**: 画面をクリックすると、24時間・週間の予報と現在の詳細が開きます
- **地点を変える**: 画面の地名をクリックします
- **設定を開く**: 左下の歯車をクリックします。デザイン、ネオンの色、ちらつきを変えられます

| キー | 動作 |
|---|---|
| `S` | 設定を開く・閉じる |
| `1` `2` `3` | デザインを切り替える |
| `N` | ネオンの色を変える |
| `F` | ネオンのちらつきのオン・オフ |
| `Esc` | 開いている画面を閉じる |

## 注意

- 表示は参考情報です。気温や雨量は予報モデルの値で、実際と異なることがあります。防災上の判断は、気象庁や自治体の発表を確認してください
- 気象庁のデータは公式のAPIではないため、形式の変更で警報表示が動かなくなることがあります
- 仙台市や釧路市のように、気象庁が市内を分割して発表している市区町村では、先頭の区域の警報を表示します

## データの出典

- 天気予報: [Open-Meteo](https://open-meteo.com/)(CC BY 4.0)
- 警報・注意報: [気象庁ホームページ](https://www.jma.go.jp/bosai/warning/)の情報を加工して表示
- 地名と座標: [Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)(CC BY 4.0)
- 書体: しっぽり明朝、Zen Kaku Gothic New、Cormorant Garamond、Jost(SIL Open Font License)

## 開発者向け

ここから下は、コードを手元で動かしたり、改造して自分のサイトとして公開したりする人向けです。
使うだけなら読む必要はありません。

### 手元で動かす

[Node.js](https://nodejs.org/) 20以降が必要です。

```bash
npm install
npm run dev
```

Windowsでは `天気を開く.bat` をダブルクリックすると、ビルドして Edge のアプリウィンドウで開きます。

公開用のファイルは `npm run build` で `dist` フォルダーに出力されます。
サーバー側の処理はなく、相対パスで出力するので、任意の静的ホスティングにそのまま置けます。

### 背景を確認するためのURL

URLの末尾に付けると、実際の天気に関係なく背景を確認できます。文字は実際の天気のままです。

- `?demo=clear` `partly` `cloudy` `rain` `heavy` `snow` `blizzard` `fog` `thunder`
- `&wind=5` 風速(m/s)
- `&hour=21` 時刻(0〜23)
- `&alerts` 架空の警報を表示

### 自分のサイトとして公開する

このリポジトリは、`main` に push するたびに GitHub Pages へ自動で公開されます(`.github/workflows/deploy.yml`)。
フォークして同じように公開するには、フォーク先の Settings → Pages → Source で「GitHub Actions」を選んでください。

Open-Meteo の無料枠は非商用利用に限られます。広告の掲載や有料での提供をする場合は、Open-Meteo の有料プランが必要です。

### 地名データを作り直す

```bash
npm run places
```

Geolonia 住所データをダウンロードし、市区町村ごとの読みと代表座標を `public/places.json` に書き出します。
